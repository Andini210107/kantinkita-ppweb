# Desain Responsif KantinKita

KantinKita dirancang agar dapat digunakan melalui berbagai ukuran layar.

## Perangkat
- Desktop
- Laptop
- Tablet
- Smartphone

## Tujuan
- Menjaga tampilan tetap rapi pada berbagai ukuran layar.
- Memudahkan navigasi pengguna.
- Menyesuaikan tata letak konten dengan ukuran perangkat.

## Pendekatan
Desain menggunakan CSS dan Tailwind CSS untuk mengatur tata letak serta responsivitas antarmuka.
