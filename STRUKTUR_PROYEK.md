# Struktur Proyek KantinKita

## Folder src
- components: Komponen antarmuka yang digunakan kembali.
- pages: Halaman aplikasi pembeli dan penjual.
- routes: Pengaturan navigasi antarhalaman.

## Folder public
- data: Data JSON untuk kebutuhan aplikasi.

## File Konfigurasi
- package.json: Informasi proyek dan dependensi.
- vite.config.js: Konfigurasi Vite.
- index.html: Dokumen HTML utama.
