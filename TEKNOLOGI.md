# Teknologi KantinKita

Teknologi yang digunakan dalam pengembangan aplikasi:

1. React: Membangun antarmuka pengguna berbasis komponen.
2. Vite: Menjalankan development server dan proses build.
3. JavaScript: Mengatur logika dan interaksi aplikasi.
4. Tailwind CSS: Mengatur tampilan dan desain responsif.
5. React Router: Mengatur navigasi antarhalaman.
6. Lucide React: Menyediakan ikon antarmuka.
7. Fetch API: Mengambil data dari file JSON lokal.
8. Local Storage: Menyimpan data tertentu pada browser.
