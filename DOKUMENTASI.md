# Dokumentasi KantinKita

KantinKita adalah website pemesanan makanan dan minuman kantin kampus.

Fitur:
- Login dan registrasi.
- Melihat kantin dan menu.
- Pencarian makanan.
- Keranjang dan checkout.
- Pemantauan pesanan.
- Ulasan dan rating.
- Pengelolaan menu dan pesanan penjual.

Teknologi:
- React
- Vite
- Tailwind CSS
- JavaScript
- React Router
- Fetch API
