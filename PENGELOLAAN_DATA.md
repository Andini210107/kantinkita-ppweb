# Pengelolaan Data KantinKita

## Sumber Data
Aplikasi menggunakan file JSON lokal sebagai sumber data kantin dan menu.

## Pengambilan Data
Data diambil menggunakan Fetch API pada halaman yang membutuhkan informasi kantin dan menu.

## Penyimpanan Data
Local Storage digunakan untuk menyimpan data tertentu agar tetap tersedia selama pengguna menggunakan browser.

## Tujuan
Pengelolaan data membantu aplikasi menampilkan informasi secara terstruktur dan mendukung interaksi pengguna.
