# KantinKita

Website pemesanan makanan dan minuman kantin kampus Telkom University yang memudahkan mahasiswa mencari kantin, memilih menu, melakukan pemesanan, dan memantau status pesanan. Penjual juga dapat mengelola menu dan pesanan.

## Fitur Utama

### Pembeli
- Registrasi dan login.
- Melihat daftar kantin dan menu.
- Mencari makanan dan minuman.
- Menambahkan produk ke keranjang.
- Melakukan checkout.
- Memantau status pesanan.
- Memberikan ulasan dan rating.

### Penjual
- Dashboard penjual.
- Mengelola menu.
- Mengelola pesanan masuk.
- Memperbarui status pesanan.
- Melihat ulasan pembeli.
- Mengelola informasi kantin.

## Teknologi
- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Lucide React
- Fetch API
- Local Storage

## Persyaratan
- Node.js
- npm
- Git

## Cara Menjalankan Proyek

1. Clone repository:
   git clone https://github.com/Andini210107/kantinkita-ppweb.git

2. Masuk ke folder:
   cd kantinkita-ppweb

3. Instal dependensi:
   
pm install

4. Jalankan aplikasi:
   
pm run dev

5. Buka alamat lokal yang ditampilkan Vite di browser.

## Struktur Proyek
- src/components — Komponen antarmuka.
- src/pages — Halaman aplikasi.
- src/layouts — Layout halaman.
- src/routes — Konfigurasi navigasi.
- public/data — Data JSON aplikasi.
