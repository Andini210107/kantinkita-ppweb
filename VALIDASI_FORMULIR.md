# Validasi Formulir KantinKita

Validasi formulir digunakan untuk membantu pengguna memasukkan data dengan benar.

## Registrasi
- Nama wajib diisi.
- Email wajib diisi dengan format yang valid.
- Password wajib diisi.
- Konfirmasi password harus sesuai.

## Login
- Email wajib diisi.
- Password wajib diisi.

## Checkout
- Informasi pemesanan wajib dilengkapi.
- Keranjang harus memiliki produk sebelum checkout.

## Tujuan
Validasi membantu mengurangi kesalahan input dan meningkatkan kemudahan penggunaan aplikasi.
