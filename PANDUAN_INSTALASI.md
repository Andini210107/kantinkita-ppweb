# Panduan Instalasi KantinKita

## Persyaratan
- Node.js dan npm.
- Git.
- Visual Studio Code atau editor kode lainnya.

## Langkah Instalasi
1. Clone repository KantinKita.
2. Masuk ke folder proyek.
3. Jalankan npm install untuk memasang dependensi.
4. Jalankan npm run dev untuk memulai aplikasi.
5. Buka alamat lokal yang ditampilkan oleh Vite pada browser.

## Menjalankan Build
Jalankan npm run build untuk membuat hasil build aplikasi.
